# Data

This folder contains the cleaned sample dataset and its documentation.

## Collection

The sample comes from a one-time test of the [Bear Blog Discovery RSS feed](https://bearblog.dev/discover/feed/), collected on November 8, 2026, at 7:39 p.m. Mountain Time.

The feed returned 20 entries. All 20 were successfully cleaned.

## Files

- `cleaned_sample.csv` — A public sample containing 10 cleaned records from the test collection.
- `data_dictionary.md` — Definitions of each field in the cleaned dataset.
- `raw/` — Raw RSS snapshots are stored locally but excluded from the public repository.

The complete raw feed and full cleaned dataset are excluded to avoid unnecessary redistribution of the feed and individual post links.

This is a preliminary test, not the completed 14-day study.
